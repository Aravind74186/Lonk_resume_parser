## 🧠 Lonk Resume Parser

**Lonk Resume Parser** is an AI-powered bulk resume parsing tool built with Django on the backend and a clean HTML/CSS/JS frontend. It supports parsing resumes in **PDF, DOC, and DOCX** formats, extracting key information using the **Gemini API** and **Hugging Face NLP models**.

### 🚀 Features

- 🔍 **Bulk Resume Parsing** – Upload multiple resumes at once and extract structured data instantly  
- 🤖 **AI Integration** – Utilizes **Google's Gemini API** and **Hugging Face models** for intelligent information extraction  
- 📄 **Multi-format Support** – Works seamlessly with PDF, DOC, and DOCX files  
- 🛠️ **Django Backend** – Robust backend with easy scalability and API support  
- 🌐 **Frontend Interface** – Simple, responsive UI using HTML, CSS, and JavaScript for ease of use  

### 📦 Tech Stack

- **Backend**: Django, Gemini API, Hugging Face Transformers  
- **Frontend**: HTML, CSS, JavaScript  
- **Parsing Libraries**: `python-docx`, `PyPDF2`, `docx2txt`, etc.

### 🔧 Use Cases

- Recruitment automation  
- Candidate database generation  
- HR analytics tools  
- Resume classification and screening
